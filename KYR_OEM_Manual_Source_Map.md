# KYR — OEM Owner's-Manual Source Map (navigation aid)
### Know Your Ride Technologies LLC · 21 June 2026

> **What this is.** A navigation map to each manufacturer's **own free owner's-manual portal** — the clean, citable **Tier-1 source** for the free verification stream (oil/fluids/coolant/tire/intervals → `owner-manual-verified`). It tells a researcher *where the manual lives* and *how to reach it* per make.
>
> **Provenance discipline (non-negotiable).** The portal list was *navigated to* via a third-party directory article (CARFAX). **CARFAX/the directory is used ONLY to find each OEM's own portal — it is NEVER cited for any spec value.** Every fact written to the DB is cited to the **specific OEM manual + printed page** (the [Source Authority Matrix](KYR_Source_Authority_Matrix.md) rule). A value is `owner-manual-verified` only when pulled from the manufacturer's own manual, confirmed to match the vehicle (self-ID on p1), and page-cited.
>
> **No DB writes** — this is a routing aid. Companion to **§2 of `KYR_Verification_Pipeline_Design.md`** (which characterizes the same portals for the *extraction tool*: PDF host pattern, Self-ID, Grade). This file adds the **navigation lens**: portal type, VIN requirement, year coverage, access confidence.

---

> ## ⚠️ STANDING RULE — Engine config is NOT generation-stable
> **Before writing dual-value (multi-engine) strings across a generation's year-rows, verify each year's actual engine options against its own manual.** Engine options get added/dropped mid-generation — **Mazda 3 Gen 2 added SkyActiv mid-cycle**; **Altima 2.0T dropped 2025**; **Sentra B17 1.6T turbo launched 2017** (absent 2013–2016). **Never assume the lineup is stable.** A generation-representative manual covers the spec *values* (generation-stable), but the *engine roster* is per-model-year — cheap to check (grep each year's PDF for the engine codes). Write a dual-value string to a year **only if that year actually offered both engines**; single-value otherwise. **Flag uncertain years rather than guess — leave them gated.** (Full rule in `KYR_Verification_Pipeline_Design.md` §1.)

## Key takeaways for the free OM stream

1. **The owner's-manual portals are overwhelmingly clean Tier-1 access.** Of the six high-volume un-piloted makes characterized this pass, **five (Ford, Chevrolet, Nissan, Subaru, Hyundai) are direct, login-free, VIN-free PDFs** reachable by year+model — they qualify as VERIFIED (manufacturer) sources under the [data-integrity gate](KYR_Source_Authority_Matrix.md). Plus Honda + Mazda already in production = **7 of the top makes are confirmed-reachable.**
2. **VIN is NOT required** for the owner's manual on any portal checked — year+model selection reaches it. (VIN walls appear for *service* info, not the owner's manual.) This keeps the free stream frictionless.
3. **Toyota (348, our #1) is the lone hard case** — a JS/SPA viewer with no plain-fetch PDF. It needs a real-browser/headless pilot to extract the manual URL, OR fall back to the addressable Quick Reference Guide for the limited fields it carries (per §2, Toyota is also Grade-D for Self-ID — the full OM doesn't name the model inside, so model-match must be confirmed another way).
4. **Two access wrinkles to plan for:** GM (Chevy/Cadillac/Buick/GMC) returns **403 to non-browser User-Agents** — spoof a normal UA; and several portals (Nissan, Subaru, Ford, GM) changed PDF **filename schemes across eras** — run a short per-make URL-template probe before any bulk pass.
5. **Corporate-sibling inheritance cuts the work:** characterizing one brand unlocks its group — **GM** (Chevy→Cadillac/Buick/GMC), **Honda** (Honda→Acura, both `techinfo`), **Ford** (Ford→Lincoln), **VW** (VW→Audi), **Stellantis/Mopar** (Dodge→Jeep→Ram→Chrysler). ~8 portal characterizations cover the top ~20 makes.

### ★ Nissan pilot finding (June 2026) — torque bonus changes Nissan's value
Piloted on the Altima L34 (2019–2025). **Nissan's owner's manual publishes the claim-critical service-torque fields that Honda's and Mazda's OMs omit** — **drain-plug torque (22–28 ft-lb, §8-12), oil-filter torque (11–15 ft-lb, §8-12), and lug torque (83 ft-lb, §6-8)** — all manufacturer-authoritative, so they go straight in as `owner-manual-verified` with no service-manual stage. **This means Nissan vehicles get *more* verified from the free stream than Honda/Mazda do** (including drain-plug torque, an audit claim-critical field). Still gated for Nissan: spark-plug type/gap, battery group/CCA, CVT-fluid capacity (NS-3 *type* is in the OM; capacity isn't).
- **Spec layout is multi-section** (not one consolidated table like Mazda): fluids/capacities §10-2/10-3, tire **size** §10-9, tire **pressure** §8-33, **torque** §8-12 & §6-8, maintenance §9. Engine codes (**PR25DD** 2.5L / **KR20DDET** 2.0T VC-Turbo) split the specs → a per-make locator needs ~5 page anchors.
- **Verify engine config per model-year, don't assume:** the L34 2.0T was offered **2019–2024, dropped for 2025** — confirmed by probing each year's own manual (the "2021+ is 2.5L-only" assumption was wrong by four years). Cheap to check: grep each year's PDF for the turbo engine code.
- **Time:** ~30 min for the generation (more sections than Honda, but spec-dense and reliable; no 403/login).

### ★ GM Duramax diesel supplements — separate "MUL" (multi-model, Chevy/GMC shared) docs, on `contentdelivery.ext.gm.com/.../owners_manuals_browse/`
GM ships diesel specs in a **separate supplement**, NOT the main OM (the gas OM punts all diesel oil/coolant/ATF/capacities/parts to it). **THREE distinct Duramax supplements — three different engines, three different oils; do NOT confuse them (the brand name "Duramax" is shared, the specs are NOT):**
- **2.8L Duramax (LWN)** — small light-duty 4-cyl, MIDSIZE Colorado/Canyon (also diesel vans). Supplement filename `<YY>-2.8l-duramax-diesel-supplement.pdf` (chevrolet.com dam `.../<YY>/chevrolet/{colorado,multimodel}/`). Oil = **dexos2 0W-40**; cooling **11.1 qt (pickup)**; DEF **5.5 gal**; pairs with a **6-speed**. Multi-model doc → read the **Pickup/LWN** row specifically (van values differ). **NOT EPA-exempt** (light-duty → use EPA to confirm year span). USED: Colorado/Canyon 2016–2022. PILOT-CONFIRMED (Colorado/Canyon, 2026-06-26).
- **3.0L Duramax (LM2/LZ0)** — light-duty 1500 + full-size SUVs. Filename `<YY>_MUL_Duramax_Diesel_3.0L_SUP_…`. Oil = **0W-20 dexos D**, ~7.0 qt; DEF ~5.3–5.4 gal; pairs with the 10-speed (DEXRON ULV). **LM2 (SUV) vs LZ0 (pickup)** differ on coolant/DEF/filters (read per config). USED: Silverado/Sierra 1500 (2020+), Tahoe/Suburban/Yukon/Escalade (LM2 SUV).
- **6.6L Duramax (L5P)** — HD 2500/3500. Filename `<YY>_MUL_Duramax_Diesel_6.6L_SUP_…` (note: 2020 doc uses `6_6L`). Oil = **15W-40 CK-4** (NOT dexos D!), **10.0 qt**; cooling **30.7 qt + 3.7 qt low-temp loop**; DEF **7.0 gal**; **Allison** transmission (DEXRON ULV / Allison TES). USED: Sierra/Silverado 2500HD/3500HD. PILOT-CONFIRMED (Sierra 2500HD T1XX-HD, 2026-06-26).
- **★ Oil-spec at a glance: 2.8 LWN = dexos2 0W-40 · 3.0 LM2/LZ0 = dexos D 0W-20 · 6.6 L5P = 15W-40 CK-4.** Each read from its OWN supplement — never carry one Duramax's value to another.
**HD trucks are EPA-EXEMPT (>8,500 GVWR)** → engine roster comes from the OM/GM specs, not fueleconomy.gov. **HD ≠ 1500:** HD keeps **hydraulic PS** (2.1 qt) where the 1500s went EPS; gas L8T = 5W-30 (vs 1500 6.2's 0W-20). HD axles punt to dealer (gate).

The midsize trucks are their own gas-engine set, NOT the 1500/HD V8s nor the Buick crossover engines. **Most layered nameplate: three steering/brake regimes across three gens — read each independently:**
- **1st gen (2004–06):** 2.5/3.6 not yet — **2.8L I4 (LK5)** 5.0 qt + **3.5L I5 (L52)** 6.0 qt, **5W-30 GM6094M**, gap 0.042, **HYDRAULIC PS / DOT 3**. 1st-gen OM *prints* axle fluids (75W-90 rear / 80W-90 front). Lug → spec-page (gate if not legible).

- **3rd gen (2023+):** single **2.7L turbo I4 (L3B)** 5W-30 dexos1, 6.0 qt, cooling 11.6, gap .026–.030. **EPS / DOT 4** (2023 redesign flips DOT 3→4 and collapses the 3-engine roster to one). Lug 140.

## ★★ SUBARU — make characterization (PILOT-CONFIRMED 2026-06-27: Outback + Forester + Crosstrek + Impreza + Legacy + Ascent) — reuse for WRX/old-gen
**First non-GM make. NOTHING from GM carries.** This section is the durable asset — it solves "how do I know I'm holding the right manual?" for the entire Subaru line. **Pattern proven across 6 siblings** (mainstream line essentially done), incl. the **Crosstrek⇄Impreza platform-twin pair** AND the **Legacy⇄Outback combined-manual pair** (both closed); refinements below from all six.
- **HOST (manufacturer):** `https://cdn.subarunet.com/stis/doc/ownerManual/<DOCNUM>.pdf` — CDN edge of Subaru's dealer-network domain; serves the authoritative OM PDF **without auth**. (`techinfo.subaru.com` and `www.subarunet.com` both redirect to a Subarunet **dealer login** — use the cdn edge.) Browser-UA + `Referer: https://www.subaru.com/`.
- **⚠ GITHUB 100MB LIMIT (general workflow note — applies to any large-OM make):** GM OMs ran ≤32MB and were committed; **Subaru OMs are 98–114MB, over GitHub's hard 100MB limit** → the push is rejected. Fix: **gitignore the OM PDF, keep it locally, put provenance in the commit message + this source map** (doc number + self-ID code). The **data (`data.*.js`) and the write script are what need versioning; the OM is a source you read, not a build artifact.** Expect this on other import/foreign makes with high-res manuals.
- **⚠ SELF-ID — NEVER trust the filename.** `MSA5M` is a **shared family prefix**, not a model id: `MSA5M0803A` = **2008 Forester**, not Outback. Confirm the MODEL from the body:
  - **Model-code footer** `北米Model "A####BE-…"` → **A25xx = Legacy/Outback** (A2570 MY20, A2540 MY18); **A82xx = Forester** (A8230 MY18, A8240 MY19; older A81xx, A8130 MY08); **A13xx–A16xx = Crosstrek**; **A13xx–A16xx (+10) = Impreza** (shares Crosstrek's block — see platform-twin below); **A32xx = Ascent** (A3220 MY21, A3270 MY26 — unique block, no twin). **Filename model-code segment:** Impreza="01", Forester="02", Outback/Legacy="03"(+"04"), WRX="05", Crosstrek="07", **Ascent="00"**. The model code is the primary self-ID — EXCEPT see the platform-twin case below.
  - ⚠ **Name-mention count is NOT a reliable self-ID — it depends on combined vs standalone.** Combined manuals (Legacy+Outback) say the model name often (Outback ×192) → high count. **Standalone manuals (Forester, Crosstrek, expected Impreza) say it ~0 times** — they just say "your vehicle" + identify by a **vehicle illustration** (front-matter, ~page 2–3) + model code. A zero own-name count is **normal, not a failed self-ID.**
  - ⚠⚠ **PLATFORM-TWIN case (Crosstrek ⇄ Impreza) — the third self-ID refinement, CONFIRMED in both directions (the pair is now a closed matched set):** Crosstrek and Impreza **share the A1xxx body model-code**, so the code alone does NOT distinguish them. The discriminator is the **cross-model name DIFFERENTIAL: own-model ≥ 0 AND twin = 0.** Crosstrek OM = `crosstrek ≥ 0` AND **`impreza = 0`**; Impreza OM (verified mirror) = `impreza ≥ 0` AND **`crosstrek = 0`**. Filename model-code segment also distinguishes: Crosstrek **"07"**, Impreza **"01"** (Forester "02", Outback "03"/Legacy, WRX "05") — the model-specific part of the doc number, NOT the shared `MSA5M` prefix.
    - ⚠ **The codes are ADJACENT — Impreza = Crosstrek +10:** Crosstrek A1370(20)/A1520(24)/A1630(26) vs Impreza A1380(20)/A1530(24)/A1640(26). **A code-PREFIX rule ("A13–16xx = Crosstrek") would mis-claim EVERY Impreza as a Crosstrek** — this is the concrete proof that the *differential*, not the code prefix, must be the gate. (WRX is a separate model string in the DB — exclude; turbo specs stay out of base Impreza.)
  - ⚠ **Crosstrek front illustration is a CCITT-G4-fax raster** that pdfplumber/PIL can't cleanly render here — KNOWN FOLLOW-UP needs a renderer not in this env (fitz/pdf2image). Self-ID held via the differential + filename "07" + provenance instead (a *stronger* discriminator for the twin question than the illustration).
  - **Model year lives in the doc number** (`MSA5M`**`2003`**`A` = MY2020, YYMM), **never printed in the body**.
- **Manual structure:** Legacy+Outback = **combined** ("03" book, A25xx code — read BOTH columns: the Outback slice took the Outback column, the Legacy slice took the Legacy column from the *same* PDFs). **Forester / Crosstrek / Impreza = standalone.** `MSA5M` = full Owner's Manual; `MSA5B` = Getting Started guide (no spec tables — skip). ⚠ Beware partials: some `MSA5M..13..` docs are 140–216pp supplements with NO Specifications chapter (e.g. 2021 `2113A`, 2025 Forester `2513B`) — verify a Specs chapter exists before trusting; if the full combined OM isn't on the CDN, use the prior-year gen-rep + EPA stability note.
